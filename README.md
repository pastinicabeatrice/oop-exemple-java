# Exemple OOP în Java

Exemple de curs pentru Java și programarea orientată pe obiecte.

## Ce conține

- `basicStuf` - variabile, operatori, decizii și bucle
- `oop` - clase simple (`Animal`, `ContBancar`, `Masina`, `Student`, `Telefon`) și încapsulare
- `oop.polimorfism` - supraîncărcarea și suprascrierea metodelor
- `abstractie` - clase abstracte și interfețe
- `designPatternuriCreationale.Singletone` - variante de Singleton (lazy, thread-safe, helper)
- `designPatternuriCreationale.exercitiuSingletone` - logger, manager de configurație (`config.properties`) și autentificare implementate ca Singleton

## Rulare

Se deschide folderul în IntelliJ IDEA și se rulează clasa `Main` din pachetul dorit.
